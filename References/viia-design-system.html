01 — Stack actuelle

Ce qui fait tourner le site

Un site statique généré à la build, avec deux routes API légères pour le formulaire de contact et le numéro de téléphone masqué.

Framework
Astro 7.2 — TypeScript, Content Layer API pour l'éditorial
Rendu
Statique par défaut (output: 'static'), hybride sur 2 routes (prerender = false) pour /api/contact et /api/phone
Hébergement
Vercel — déploiement auto sur push vers main
Domaine
viia.pro via Vercel DNS
Analytics
Vercel Web Analytics — choisi pour éviter le bandeau cookies obligatoire de GA
Email
Resend — domaine sandbox, à vérifier avant montée en charge
Anti-spam
Cloudflare Turnstile + honeypot
SEO
@astrojs/sitemap, robots.txt, Search Console (propriété domaine)
Ce qui manque
Aucune base de données, aucune authentification, aucun temps réel

Les deux terrains

Section claire Texte en charbon sur fond crème — le mode par défaut, utilisé sur la majorité des sections.
Section sombre Texte blanc à 78% d'opacité sur fond noir — réservé aux sections à fort impact (visuels, citations).
Question ouverte

Le "jaune du tracé GPS" n'existe pas aujourd'hui — il n'y a ni carte ni GPS dans le repo actuel, et #EBED38 est la seule couleur de marque du site entier. Recommandation : réutiliser cet accent tel quel pour le tracé plutôt que d'introduire un second jaune. S'il se noie sur un fond satellite (probable — beaucoup de bâti est déjà jaune-brun), corriger avec un liseré de contraste (accent + contour noir 1-2px) plutôt qu'une nouvelle teinte.

03 — Typographie

Une seule famille, deux registres

Space Mono partout — aucune police secondaire. Le ton "données opérationnelles" vient de la graisse et de la casse, pas d'un mélange de polices.

Les zones délaissées ne le sont plus.

Corps de texte en régulier, ~85% d'opacité. Les titres sont toujours en graisse 400 (jamais 700) et en majuscules — c'est la règle de maison, y compris pour les gros titres.

08 — Pour le dashboard

Ce qui sert, ce qui manque

Le site vitrine n'a ni base de données, ni authentification, ni temps réel — normal, ce n'est pas son rôle. Voici ce qui se transporte tel quel et ce qui reste à choisir dans la nouvelle session.

À reprendre
La palette, Space Mono, les data-labels et la grille "carte de rapport" (déjà utilisée pour le rapport d'intervention sur la home) — le style colle naturellement à un dashboard d'opérations.
À adapter
Astro peut servir de coquille (pages statiques, marketing du dashboard) mais une app authentifiée avec carte GPS temps réel voudra des îlots interactifs React/Vue ou un framework plus orienté app (Next.js, SvelteKit) pour la partie connectée — à trancher selon la charge temps réel voulue.
Net nouveau
Authentification client, base de données (positions GPS, opérations, historique), ingestion temps réel des positions opérateurs, librairie de cartographie (Mapbox / MapLibre / Leaflet) — rien de tout ça n'existe dans le repo actuel.
